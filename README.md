# ❌ Tic-Tac-Toe
A 2-player Tic-Tac-Toe game with win detection and score tracking.

**Live Demo:** https://maryamshuaibumusa706-netizen.github.io/tic-tac-toe/

### Features
- 2-player X vs O gameplay
- Win / Draw detection
- Score tracker (X, O, Draws)
- Play Again reset

### Tech Used
- HTML, CSS Grid, JavaScript

### What I Learned
- Game state with arrays
- Win-condition logic
- DOM event handling
